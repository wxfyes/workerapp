# 工友记工 (WorkerApp) - 计件工资与月度薪资核算

专为一线按件计薪工友打造的**纯单机安全离线版**安卓记工记账应用。

---

## 一、 已生成的安卓安装包 (APK)

在项目根目录下已为您直接编译好安装包：
👉 **[`工友记工_v1.0.apk`](file:///e:/GitHub/workerapp/工友记工_v1.0.apk)** (体积仅 4.08 MB)

1. 直接将该 `.apk` 文件通过微信/QQ发送到手机；

3. 在手机上点击安装包，根据提示允许安装即可运行。

## 二、 核心功能特色

### 1. 每天临时手输 (极速爽快)
* **大按键/计算器级录入体验**：输入【数量】×【单价】，实时算出金额。
* **智能历史联想**：输入过的工序和品名会自动记录在快捷标签中，下次点一下秒带入名称和单价。
* **一日多笔**：同一天内做多种不同工件，可连续添加，支持修改与删除。
* **快捷加量**：内置 `+10`、`+50`、`+100` 快捷按钮。

### 2. 特殊计算与补贴核算体系
* **工龄补贴**：可在【设置】中配置每月默认金额，并在月核算中自由调整。
* **高温补贴（特定支持）**：针对“一年就一次，也可能没有”的特性设计：
  * 平常月份不发即填 `0` 元（显示为本月无高温补贴）。
  * 到了发放月份（如夏季）直接填入实际发放金额（如 `+¥300`），实时计入当月实得。
* **全勤奖 / 保底底薪**：支持录入与公式自动合算。
* **自定义补贴加项**：夜班餐补、技术津贴等随时添加。
* **代扣除款项**：支持借支预支生活费、水电扣款、社保等扣除项。
* **综合薪资公式**：
  $$\text{本月实发总额} = \text{计件纯工钱} + \text{工龄/高温/全勤/日补贴加项} - \text{各项扣款}$$

### 3. 工资日历与明细大屏
* **工薪日历**：按月展现，哪天赚了多少钱在日历格子上直接标注；点击某天即刻展开当日流水。
* **月度综合对账**：展示出勤天数、日均计件收入、完成总件数。

### 4. Excel 对账单导出与文字账单
* **一键导出 Excel (.xlsx)**：生成规范的月度对账表（含汇总大表与每日明细清单），发工资核对一目了然。
* **一键复制文字账单**：生成清晰纯文本，一键发到微信。

### 5. 100% 本地离线与数据防丢
* 无需连网、无服务器、不偷跑流量、绝对保护工价隐私。
* 支持一键导出 `.json` 备份文件，换手机也能轻松恢复。
